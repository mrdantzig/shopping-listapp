# 쇼핑 리스트 앱 🛒

간단한 바닐라 JavaScript 기반 쇼핑 리스트 웹 앱입니다. 별도의 빌드 과정이나 서버 없이 브라우저에서 바로 실행됩니다.

## 기능

- 물건 추가 / 삭제
- 완료 체크(취소선 표시)
- 완료된 항목 일괄 삭제
- 남은 개수 / 완료 개수 요약 표시
- `localStorage`를 이용한 데이터 저장 (새로고침해도 목록 유지)
- 라이트 / 다크 모드 자동 대응 (시스템 설정 기반)

## 사용 방법

`index.html` 파일을 브라우저로 열기만 하면 바로 사용할 수 있습니다.

```bash
git clone https://github.com/mrdantzig/shopping-listapp.git
cd shopping-listapp
# index.html을 브라우저로 열기
```

## 기술 스택

- HTML / CSS / JavaScript (프레임워크 없음)
